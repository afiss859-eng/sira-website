# SIRA — Site officiel

Site vitrine responsive de l'association SIRA — « Chemin d’aujourd’hui, avenir de demain ».

## Structure
- `index.html` — page d'accueil et sections institutionnelles
- `styles.css` — identité visuelle, responsive et composants
- `app.js` — navigation mobile et formulaire de contact (front-end)
- `assets/sira-logo.png` — logo officiel fourni pour le projet

## Prochaine évolution
Les informations institutionnelles officielles, coordonnées, projets réels, réseaux sociaux et éventuels moyens de don seront renseignés avant la mise en production. Le site est préparé pour évoluer vers un backend, un espace d'administration, les adhésions, les événements et les contenus dynamiques.
